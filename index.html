📊 구글 스프레드시트 연동 설정

💡 Google Apps Script 웹 앱 배포 URL을 입력해두면, 구글 시트와 실시간으로 명단을 가져오거나 배정 결과를 자동 기록할 수 있습니다.

URL을 한 번 입력해두면 브라우저에 안전하게 기억됩니다.

  1. 선생님의 구글 스프레드시트 메뉴에서 [확장 프로그램] → [Apps Script]를 엽니다.
  2. 아래 스크립트 코드를 복사하여 붙여넣고 저장합니다.
  3. 오른쪽 상단 [배포] → [새 배포]에서 유형을 [웹 앱]으로 선택합니다.
  4. 액세스 권한을 [모든 사용자(Anyone)]로 설정 후 배포하고 발급된 웹 앱 URL을 위에 입력하세요.
// Google Apps Script 연동 템플릿 코드
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sSheet = ss.getSheetByName("학생명단") || ss.getSheets()[0];
  var students = sSheet.getDataRange().getValues().slice(1).map(r => r[0]).filter(Boolean);
  return ContentService.createTextOutput(JSON.stringify({ students: students }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var out = ss.getSheetByName("배정결과") || ss.insertSheet("배정결과");
  (data.assignments || []).forEach((a, i) => {
    out.appendRow([new Date(), data.className, i+1, a.student, a.roleName, a.roleDesc]);
  });
  return ContentService.createTextOutput(JSON.stringify({ status: "ok" }));
}
